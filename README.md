**Digital EduResolve: A Digital Help Desk System**

EduResolve is a real-time grievance redressal ecosystem that connects students, help desk agents, and administrators. It replaces manual paperwork with a transparent, automated digital workflow.

Core Functionality:
Students: Submit tickets with a unique 8-digit ID and track live status updates.
Help Desk: A professional terminal for staff to claim, manage, and resolve campus issues.
Admins: A KPI dashboard to monitor campus health and flag tickets delayed over 5 days.
Live Notifications: A Transmission Console simulates real-time data dispatch for every status change.

Tech Stack & Tools:
Language: Python 3.x
Web Framework: Streamlit
Database: SQLite3
Data Analysis: Pandas
Deployment: GitHub & Streamlit Community Cloud

Quick Start:
pip install streamlit pandas
streamlit run digitalResolve.py
